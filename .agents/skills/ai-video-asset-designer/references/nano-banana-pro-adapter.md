# Nano Banana Pro 适配器

## 适用范围

Nano Banana Pro 作为按需适配目标，只有用户明确选择它时才使用。Google 官方图像生成文档当前把 Gemini 3 Pro Image（常称 Nano Banana Pro）列为适合复杂、专业资产生成的模型；访问核验日期：2026-07-27：<https://ai.google.dev/gemini-api/docs/image-generation>。

显示名使用 Nano Banana Pro；接口模型 ID、地区可用性、尺寸/宽高比、参考图数量和安全策略都必须在实际接入时重新核验。此仓库不安装 SDK、不保存密钥、不调用付费 API。

## 适配原则

母版事实保持不变，针对模型的版本可以：

- 把复杂资产拆成“主体身份 → 场景/背景 → 细节 → 构图/视图 → 约束”的完整自然语言段落；
- 对多张参考图逐一写明角色和优先级；
- 明确 preserve / change / do not add 三类指令，降低参考图之间互相污染；
- 对信息图、包装、UI 等资产提供逐字文字和版式，无法保证精确文字时标记后期排版风险；
- 指定输出用途；只有用户明确要求、项目规则已确认或资产用途确有需要时才加入画布比例和留白，并把 API 字段放在代码块外。

不要因为模型能够生成更长文本就添加剧本没有的背景故事、动作或镜头运动。复杂并不等于更具体的虚构。

## 参考图与变体

对于基准资产，第一张身份参考优先保持轮廓、脸部比例、服装结构或道具几何；风格/材质/构图参考分别列出仅可借用的维度。对于变体，写清“基准资产保持项”和“本变体唯一变化项”。

## 输出与回退

若用户没有明确选择 Nano Banana Pro，回退到 ChatGPT Image 2 默认适配。若模型/接口版本不可确认，输出平台中立母版并说明需要重新核验，不把猜测写成已支持的参数。适配器不执行调用、计费或结果存档；这些属于未来经用户授权的实现层。
