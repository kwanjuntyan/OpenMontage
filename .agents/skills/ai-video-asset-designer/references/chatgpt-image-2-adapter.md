# ChatGPT Image 2 适配器

## 适用范围

ChatGPT Image 2 是本 Skill 的默认目标。这里的“默认”只表示 Prompt 先按该模型的公开图像能力组织，不代表会自动调用 API 或自动生成图片。当前适配依据 OpenAI 官方图像生成 Prompt 指南（访问核验日期：2026-07-27）：<https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide>。

模型显示名与接口模型 ID 分开保存。面向用户显示 ChatGPT Image 2；将来接入接口时再由实现层确认具体模型 ID、尺寸、质量、背景和参考图字段。不要把未核验的接口参数写进资产 Prompt 正文。

## Prompt 组织

母版转换为适配版时，优先使用清晰、具体、分段的自然语言：

1. 场景/背景与画布意图；
2. 主体身份和几何结构；
3. 材质、服装、颜色、纹理与状态；
4. 视图、构图、留白和输出用途；
5. 参考图角色；
6. 必须保留、允许变化、禁止新增的约束。

对角色和反复出现的道具，使用 identity lock 式明确句子，逐项锁定发型、脸部比例、服装结构、标记位置、轮廓和比例。对修改类 Prompt 明确“只改变……，其余保持不变”。

## 文字与版式

图形/UI 或包装上的文字要逐字提供，并指定文字位置、方向、层级与不可替代字符。若项目没有授权的准确字样，不要让模型自行创作品牌名或剧情关键文字；将资产标为 needs_confirmation，或要求后期排版。

## 参考图

适配版在代码块中只写参考图语义，不虚构文件路径。例如：

Reference 1 (identity): preserve the subject's face proportions and clothing silhouette; do not copy its background.

真实文件路径、上传顺序、尺寸和接口参数属于调用层记录，不放入 Prompt 正文，避免一键复制后失效。

## 输出与校验

- 默认语言跟随项目资料库；需要跨平台复制时可在代码块内补充关键英文术语，但不能改变事实。
- 只有用户明确要求、项目规则已确认或资产用途确有需要时才加入画布比例、透明背景或分层留白；一旦加入就写成明确约束。无法由模型可靠保证的内容要列入 QA 风险。
- 适配版必须与母版逐项对照：身份、状态、结构、参考图角色、禁止新增项不可丢失。
- 适配器不负责生成、重试、计费、密钥或上传。只有用户明确请求直接生成且存在已授权的图像工具时，才由调用层执行。
