# kj-cinematic 視覺 Prompt 配方

本檔是 [Asset Director](asset-director.md) 的配方參考，維護素材順序、職責與 Prompt 寫法；CLP 摘錄、表演來源、工具呼叫、驗收與首幀交接由 Director 維護。
依當前步驟讀取適用的共通引用規則及一個模態章節；完成本步後回到 Director。W2I 使用參考圖說明、生圖指引、畫面描述及輸出要求；W2V 沿用五段式，其他模態使用各自寫法。
實際讀取使用 `scripts/read_prompt_recipe.py <本步模態>`，不要為了定位章節先讀全文；T2I／T2V 不輸出共通引用規則，其餘模態仍按實際素材條件套用。
範本的方括號須換成有來源的本鏡內容，不適用的選填項省略；必要資訊缺少時回報，不猜填。CLP 摘錄、表演來源與風格引用依 Director；範本標籤不代表 API 欄位，工具參數另行綁定。
八類是製作配方，不是模型能力或實測通過的保證；目前 W2I 規範較完整，其餘仍是簡要配方。

## 共通引用規則

以下按輸入條件套用，不是 Prompt 的固定段落；T2I／T2V 無參考媒體，不套本節。W2I 的外觀摘錄與空間職責依其專節：blocks 決定構圖與配置，場景圖提供外觀；可依 blocks 簡述取景與可見部位，不強制重述圖片已提供的外觀。

- **有參考媒體時**：先排實際輸入，再列各媒體的編號／名稱與用途；Prompt 全文引用須對應輸入位置。首幀、尾幀、一般參考圖及運動參考影片須分清職責，普通參考圖不等於 API 的首幀控制。
- **有 CLP 時**：各圖註名稱／CLP id／視角／用途，按 Director 的「CLP 共用描述與逐鏡摘錄」引用相關短句一次，後文以名稱／編號指稱。人物提供五官、服裝與辨識特徵；道具提供形狀、材質與辨識細節。
- **有場景 CLP 時**：它提供經核對的空間結構、物件配置與相對位置，以及材質／裝飾；從 `reference_images` 選出涵蓋本鏡可見區域的圖，核對人物位置與拍攝朝向。
- **有場景 CLP 時**：素材已清楚表達的空間定位不重述，需要消歧才補有依據的短句；這不省略必要 CLP 特徵。依經核對的 CLP 保留空間配置、物件邊界與材質特性；照片的拍攝角度與畫面左右不作為所有鏡位的依據。
- **有場景 CLP 時**：可用實圖中存在的結構邊線核對透視，只有修正具體偏差才寫入 Prompt。單張圖不能證實遮蔽區域；所需背景對不上或位置不明時先補規劃／參考，不能臆造格局。
- **選人物參考時**：鏡外對話者只作視線目標，不因對話就附其人物圖；`Single shot` 表示一個鏡頭，不代表只有一人，可見人數須明寫。

## T2I

- 寫法：主體與可見人數 → 指定瞬間的動作／姿勢 → 環境 → 構圖與攝影風格。
- 只描述同時成立的一刻，攝影規格沿用分鏡；不添加參考圖編號、白模條件或影片時間線。

### 填寫範本

```text
[主體與可見人數] 在 [規劃中的環境]，呈現 [指定瞬間的動作、表情與視線]。
[核准的景別、構圖、拍攝方向與攝影風格]。
```

## I2I

- 輸入原圖，寫清要改的目標／區域，再列須保留的外觀、構圖及其他未修改部分；共通保留規則適用於未指定修改的部分，明確指定的修改依本次要求。
- Prompt 聚焦本次差異，避免整張重新描述造成重畫；不因原圖有人物或場景就要求補 CLP／白模。實際另附 CLP 時才套其共通引用規則。

### 填寫範本

```text
以 [原圖實際引用] 為基礎，將 [指定目標／區域] 修改為 [本次指定結果]。
保留 [未指定修改且須保留的內容]。[另附參考時才列用途及必要 CLP 摘錄]。
```

## R2I

- 先引用所需 CLP 並分配用途，再寫本鏡單一瞬間的表演、可見人數、環境關係與攝影規格。
- 構圖與拍攝方向依分鏡，不要求白模。簡單鏡頭可短寫；空間複雜時補有依據的位置與視線關係，不套 W2I 模板。
- 作為後續影片首幀時，呈現核准動作的起始狀態；獨立圖片呈現指定瞬間。

### 填寫範本

```text
[實際參考圖的編號、名稱／CLP id、用途與相關描述摘錄]。
[本鏡可見人物與單一瞬間的表演、場景關係]。[核准的構圖、拍攝方向與攝影規格]。
```

## W2I

輸入場景外觀圖、blocks 構圖圖與本鏡所需人物／道具參考；使用下方唯一模板，依「參考圖說明 → 生圖指引 → 畫面描述 → 輸出」裝配，不另拆動作段落或固定風格段落。

### 素材順序與職責

- 圖片按「全部場景 → blocks → 全部人物 → 全部道具」排列；先排實際 `image_paths`，再從圖 1 起連續編號，全文圖號須一致。
- 單張場景圖時，圖 1 為場景、圖 2 為 blocks；多張場景圖相鄰排列，blocks 與其後圖號順延。不固定五張圖、兩位人物或咖啡館道具。
- blocks 提供取景、透視、物件配置、人物佔位、朝向、比例、可見範圍與遮擋；場景圖提供物件外觀、材質、風格與光影，不採用 blocks 的方塊材質或簡化外觀。
- 人物圖只提供外觀與服裝，不提供本鏡展示姿態或取景；道具圖只提供指定道具的外觀，不帶入同圖的其他物件。
- 先看實圖，核對 blocks、場景圖與 scene／camera／character 的既有 metadata 對應。缺少本鏡必要素材或有結構衝突時回報，不臆造位置或要求模型同時遵從矛盾配置。
- 多張場景圖須先確認為同一佈景，按實際可見區域補一句各圖的互補範圍，並同步替換模板中的場景圖引用；不把不同機位的左右當成本鏡左右。

### 畫面描述的填寫方式

- 先依 blocks 簡述拍攝方向、景別、人物／主體關係、可見部位與裁切，再整合本鏡表演；不是逐物件重述整個背景。
- 動作、表情、視線與道具狀態依 Director 的表演來源，以同一段描述同時成立的一個瞬間。頭部在畫外就不要求表情，手部在畫外就不要求呈現手勢。
- 指定表演需要改動的部位明寫，其餘沿用 blocks；不要同時要求改手勢又完全保留手部姿態。未指定的動作不自行加入。
- 人物及道具外觀由參考圖提供；僅在必要資訊無法由圖片提供或需消歧時補有來源的短句，不強制摘錄完整 CLP description 或加入風格前綴。
- 獨立圖片呈現指定瞬間；作為影片首幀時呈現核准後續動作的起始狀態。首幀交接與驗收回到 Director，文字與參考圖不保證像素級對齊。

### 填寫範本

以下以一張場景圖為例。依實際素材增減人物／道具行並同步圖號；無人物時省略人物替換段，無道具參考時省略道具句。方括號填妥後才送出，不送編輯註記。

```text
參考圖說明：
圖 1 [場景圖檔名]：場景外觀參考圖。
圖 2 [blocks 圖檔名]：構圖底圖。
圖 3 [人物圖檔名]：[角色名稱] 人物參考圖，對應圖 2 的 [顏色] 人物。
[其餘人物或道具參考圖依實際輸入逐一列出。]

生圖指引：
以圖 2 為編輯底圖，保留其取景、透視、物件配置、人物佔位、顯示範圍與遮擋關係。

將定位人物替換為對應角色，只呈現圖 2 中可見的部位，不補出畫外身體。人物外觀與服裝採用 [人物參考圖號]，不採用其展示姿態或構圖。

將場景的材質、風格與光影更新為圖 1 的外觀，不改變圖 2 的空間配置。
[有道具參考時：指定道具的外觀採用圖 N；該圖的其他物件不參與生成。]

畫面描述：
這是一張 [拍攝角度與景別] 的畫面。[依 blocks 簡述主體位置、人物關係、可見部位與裁切範圍]。[描述本鏡指定瞬間的動作、表情、視線及道具狀態]。除上述指定調整外，其餘沿用圖 2。

輸出一張 [畫面比例] 彩色分鏡圖，不加入字幕。
```

### 工具綁定例

本例假設已選用 Nano Banana 2.1 與 2K：`image_selector` 使用 `preferred_tool="google_imagen"`、`model="gemini-nano-banana-2.1"`、`generation_mode="edit"`、`resolution="2K"`，全部圖片依上述順序放入 `image_paths`，不另用 `image_path` 將圖片插到開頭；使用 Vertex JSON／global，比例依分鏡另填。「編輯底圖」是 prompt 中的素材職責，不是新的 API 欄位。模型與解析度沿用專案選擇，實際綁定依 Director 第 2 節查所選工具。

## T2V

- 寫法：主體與環境 → 動作起點、過程、終點 → 相機運動 → 核准時長與攝影規格。
- 保持在該時長內可完成的一段動作，表演與秒數使用 Director 已確認的規劃；不添加首幀或參考素材條件。

### 填寫範本

```text
[主體、可見人數與環境]；[核准動作的起點、過程、終點與時間節點]。
[核准相機起訖、路徑與速度]。[核准時長與攝影規格]。
```

## I2V

- 以首幀承接外觀與起始構圖，Prompt 重點寫從該畫面開始的動作、時間節點與運鏡。
- 不限微動；大動作是否能完成依模型與實測。起始動作需與首幀相容，不重寫已由首幀確定的外觀，也不要求白模影片。
- 時長與攝影規格沿用核准規劃，首幀欄位依所選工具綁定。

### 填寫範本

```text
從 [首幀實際引用] 開始，承接其外觀與起始構圖；[與首幀相容的後續動作及核准時間節點]。
[核准運鏡、時長與攝影規格]。
```

## R2V

- 按共通引用規則分清角色／場景等參考用途，再寫動作起訖、時間節點、可見人數、運鏡與攝影規格；不要求白模或 W 類五段式。
- 構圖與拍攝方向依分鏡；首尾幀是可選時間條件，不是 R2V 的唯一意思。有使用時，動作及構圖須與對應時間點相容，依工具支援綁定。
- 普通參考圖提供身份／場景依據，不自行當成固定首幀；秒數沿用 Director 已確認的規劃。

### 填寫範本

```text
[實際參考素材的編號／名稱、用途及適用的 CLP 摘錄]。[有首尾幀時才填其對應時間條件]。
[可見人數、動作起訖與核准時間節點]。[核准構圖、運鏡、時長與攝影規格]。
```

## W2V

輸入白模預演影片與核准首幀；本節使用以下五段。首幀核准與白模需求依 Director 第 3.2 節；共通交接、工具能否承接及時長限制依第 3.1 節。

### 1. 素材職責宣告

- 列核准首幀與白模影片的實際名稱／用途：首幀承接外觀及起始構圖，白模影片提供運動與運鏡依據。
- 必要 CLP 只在所選工具支援且確有用途時附加；有附加時只在素材清單引用本次需要的特徵，不重貼 W2I 全文，也不另編或重複敘述首幀已確定的外觀。

### 2. 場景與起始構圖

- 明寫核准首幀與預演 t=0 的對應；背景隨預演鏡位變化，簡化白模不能替換首幀已確定的佈景外觀。
- 核對預演與首幀／場景佈局；真有結構衝突時回報修正素材／規劃，不要求模型同時遵從矛盾幾何。

### 3. 動作與表演

- 按 Director 的「表演來源」排列動作起點、節點與終點，承接首幀狀態；以白模影片引導人物運動及相機路徑。
- 白模影片是運動引導，不保證逐幀精確重現；指定表演與預演運動無法相容時回報調整，不默默捨棄其中一項。

### 4. 畫面構成

- 依分鏡交代各動作節點的景別、可見人數、前景與主體朝向；鏡外對話者保持為視線目標。
- 只有具體誤生風險才補短約束；人物出入畫面或構圖變化依規劃，不直接沿用 W2I 靜態畫面的限制。

### 5. 攝影與時間規格

- 寫入 Director 第 3.1 節對齊後的時長、動作節點時間，以及相機起訖與速度，不擅自發明秒數。
- 沿用已核准焦段、景深、光線方向、色調、比例；預演已固定的投影與運鏡不再附加矛盾的機位指令。效果仍須以生成結果檢視。

### 填寫範本（五段）

```text
素材：[核准首幀的實際引用] 提供外觀與起始構圖；[白模影片的實際引用] 提供運動與運鏡。[必要且工具支援時才列附加 CLP 與相關摘錄]。
場景：[首幀與預演 t=0 的構圖對應；背景依核准鏡位變化，保留首幀佈景外觀]。
表演：[承接首幀的動作起點、過程、終點及指定表情、視線、手勢]，以白模影片引導人物運動。
構圖：[各動作節點的景別、可見人數、前景與主體朝向]。[依規劃的人物出入畫面及必要短約束]。
攝影：[對齊後的核准時長、節點時間與相機起訖、路徑、速度]。[核准焦段、景深、光線、色調與比例]。
```
