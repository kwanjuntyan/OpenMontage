# kj-cinematic 視覺 Prompt 配方

本檔是 [Asset Director](asset-director.md) 的配方參考，維護素材順序、職責與 Prompt 寫法；CLP 摘錄、表演來源、工具呼叫、驗收與首幀交接由 Director 維護。
依當前步驟讀取適用的共通引用規則及一個模態章節；完成本步後回到 Director。五段式只用於 W2I／W2V，T／I／R 類使用各自寫法，不從 W 類模板刪減。
實際讀取使用 `scripts/read_prompt_recipe.py <本步模態>`，不要為了定位章節先讀全文；T2I／T2V 不輸出共通引用規則，其餘模態仍按實際素材條件套用。
範本的方括號須換成有來源的本鏡內容，不適用的選填項省略；必要資訊缺少時回報，不猜填。CLP 摘錄與表演來源依 Director，Prompt 開頭沿用其選定風格；範本標籤不代表 API 欄位，工具參數另行綁定。
八類是製作配方，不是模型能力或實測通過的保證；目前 W2I 規範較完整，其餘仍是簡要配方。

## 八類分流

| 配方章節 | 本步輸入 | Prompt 重點 |
| --- | --- | --- |
| [T2I](#t2i) | 文字 | 主體、單一瞬間、環境與攝影 |
| [I2I](#i2i) | 原圖＋文字 | 修改目標、區域與保留項目 |
| [R2I](#r2i) | 所需 CLP 參考＋文字 | 素材用途、本鏡表演與構圖 |
| [W2I](#w2i) | 白模圖＋所需 CLP＋文字 | 依本節五段式生成分鏡圖或首幀 |
| [T2V](#t2v) | 文字 | 動作起訖、時間與運鏡 |
| [I2V](#i2v) | 首幀＋文字 | 承接首幀，描述後續動作 |
| [R2V](#r2v) | 參考素材＋文字 | 身份／場景參考與時間條件 |
| [W2V](#w2v) | 白模預演影片＋核准首幀＋文字 | 依本節五段式承接外觀與運動 |

## 共通引用規則

以下按輸入條件套用，不是 Prompt 的固定段落；T2I／T2V 無參考媒體，不套本節。

- **有參考媒體時**：先排實際輸入，再列各媒體的編號／名稱與用途；Prompt 全文引用須對應輸入位置。首幀、尾幀、一般參考圖及運動參考影片須分清職責，普通參考圖不等於 API 的首幀控制。
- **有 CLP 時**：各圖註名稱／CLP id／視角／用途，按 Director 的「CLP 共用描述與逐鏡摘錄」引用相關短句一次，後文以名稱／編號指稱。人物提供五官、服裝與辨識特徵；道具提供形狀、材質與辨識細節。
- **有場景 CLP 時**：它提供經核對的空間結構、物件配置與相對位置，以及材質／裝飾；從 `reference_images` 選出涵蓋本鏡可見區域的圖，核對人物位置與拍攝朝向。
- **有場景 CLP 時**：素材已清楚表達的空間定位不重述，需要消歧才補有依據的短句；這不省略必要 CLP 特徵。依經核對的 CLP 保留空間配置、物件邊界與材質特性；照片的拍攝角度與畫面左右不作為所有鏡位的依據。
- **有場景 CLP 時**：可用實圖中存在的結構邊線核對透視，只有修正具體偏差才寫入 Prompt。單張圖不能證實遮蔽區域；所需背景對不上或位置不明時先補規劃／參考，不能臆造格局。
- **選人物參考時**：鏡外對話者只作視線目標，不因對話就附其人物圖；`Single shot` 表示一個鏡頭，不代表只有一人，可見人數須明寫。

## T2I

- 寫法：主體與可見人數 → 指定瞬間的動作／姿勢 → 環境 → 構圖與攝影風格。
- 只描述同時成立的一刻，攝影規格沿用分鏡；不添加參考圖編號、白模條件或影片時間線。

### 填寫範本

```text
[主體與可見人數] 在 [規劃中的環境]，呈現 [指定瞬間的動作、表情與視線]。
[核准的景別、構圖、拍攝方向與攝影風格]。
```

## I2I

- 輸入原圖，寫清要改的目標／區域，再列須保留的外觀、構圖及其他未修改部分；共通保留規則適用於未指定修改的部分，明確指定的修改依本次要求。
- Prompt 聚焦本次差異，避免整張重新描述造成重畫；不因原圖有人物或場景就要求補 CLP／白模。實際另附 CLP 時才套其共通引用規則。

### 填寫範本

```text
以 [原圖實際引用] 為基礎，將 [指定目標／區域] 修改為 [本次指定結果]。
保留 [未指定修改且須保留的內容]。[另附參考時才列用途及必要 CLP 摘錄]。
```

## R2I

- 先引用所需 CLP 並分配用途，再寫本鏡單一瞬間的表演、可見人數、環境關係與攝影規格。
- 構圖與拍攝方向依分鏡，不要求白模。簡單鏡頭可短寫；空間複雜時補有依據的位置與視線關係，不套 W2I 五段式。
- 作為後續影片首幀時，呈現核准動作的起始狀態；獨立圖片呈現指定瞬間。

### 填寫範本

```text
[實際參考圖的編號、名稱／CLP id、用途與相關描述摘錄]。
[本鏡可見人物與單一瞬間的表演、場景關係]。[核准的構圖、拍攝方向與攝影規格]。
```

## W2I

輸入白模圖與所需 CLP；Prompt 依「參考圖內容 → 本次分鏡設定 → 參考圖使用規則 → 固定視覺風格 → 輸出」五段裝配。使用本節唯一範本，沿用 V8／V13 的段落分工；長短依本鏡需要，不為湊齊欄位或篇幅重述資訊。

- 圖片固定按「白模 → 全部場景 → 全部人物 → 全部道具」分組，每組多張相鄰排列。先排 `image_paths`，再同步 Prompt 全文引用，依實際輸入由 Image 1 起連續編號。
- 各一張時為 Image 1 白模、Image 2 場景、Image 3 人物、Image 4 道具；多張時按實際清單順延，不固定張數或可見人數。
- 第一段只交代各圖內容與識別，依 Director 摘錄本鏡必要的最少 CLP 特徵短句；不抄整段 description，也不重述完整圖片外觀。素材用途集中第三段。第二段按最新明確指示／核准分鏡選填，可合併相關設定；人物 CLP 的展示姿態不自動作為表演。
- 獨立圖片呈現指定瞬間；作為影片首幀時才呈現後續動作的起始狀態。首幀交接、驗收及影片續作依 Director，不將 W2I 當成影片。
- 第四段展開本專案已核准風格的材質、人物及光照要求，不只貼風格名稱；本鏡光線與構圖優先，風格不改 CLP 設計。無人物／道具等不適用欄位省略，不猜填缺項。
- 真有白模與 CLP 的結構衝突時回報修正素材／規劃；本鏡明確指定的姿態、互動或取景變更不直接當成衝突，先核對指定變更範圍。文字角度、焦段或「100% 鎖定」不是精度保證。

### 裝配前（給 Agent）

- 先看實圖，核對素材分工、實際圖片引用、白模取景與場景參考的對應，以及本鏡指定變更；CLP 特徵摘錄依 Director，不需將整個場景拆解轉寫為文字。
- 多張場景圖先確認同一佈景及各圖涵蓋的區域，於第三段填互補範圍；僅在具體素材歧義時另補有實圖依據的必要短句。對應無法確認時依共通引用規則回報，不補造或另編佈景。
- 保留下方五段標題與第三段通用正文，替換實際圖片引用、增減適用的人物／道具行，填入本鏡設定與核准風格／比例；除最新明確指示或具體素材歧義外，不另寫一套使用規則。
- 第三段素材分工與保留規則須送給生圖引擎，不能只作為 Agent 的內部指引或縮成「保持場景一致」。

### 分鏡欄位選單（給設計者與 Agent）

以下十項供設計者選填。Agent 依最新明確指示／核准分鏡取捨：保留指定變更、關鍵表演與需消歧的條件；未指定、不適用或已由其他段落／參考圖職責清楚交代的內容省略，不自行補設計。最終 Prompt 只寫採用的設定，可合併為短段，不附整份選單、未採用欄位或「可修改」等編輯標記。

- 劇情瞬間：本鏡呈現的事件當下、情緒與可見／畫外對象。
- 人物動作：姿勢、手部位置、互動；依最新明確指示／核准分鏡。
- 表情與視線：表情、視線方向與目標，是否看向鏡頭。
- 鏡位與景別：沿用或明確調整的鏡位、景別，以及可見範圍。
- 構圖與比例：核准比例、主體位置、朝向與留白。
- 道具位置與狀態：位置、朝向、內容物與當下接觸／離開狀態。
- 道具尺寸：本鏡尺度、與人物的比例，以及需保留的造型比例。
- 景深與對焦：主要焦點、需清楚可辨及可柔化的部分。
- 時間與光線：有指定才寫時間／天候，光源方向與補光依規劃。
- 色彩與情緒：指定色調、劇情重點與必要色彩關係。

### 填寫範本（五段）

第四段可合併材質、人物與光照要求，只寫本鏡適用內容，不逐欄重述 CLP 外觀或第二段設定。
單張場景圖沿用場景句；多張時將「提供場景設定」改為「共同提供同一場景的設定」，互補句使用「其中，[圖引用] 補充 [經核對的設計／區域]；本鏡 [可見區域／細節] 依 [圖引用]。場景圖的拍攝角度與取景範圍不決定本鏡構圖。」按各圖實際涵蓋範圍填寫，單張無歧義時省略。

```text
請使用附上的 [實際張數] 張參考圖，生成一張具有 [本專案已核准視覺風格] 的完整彩色分鏡圖。

一、參考圖內容

Image 1：[白模圖名稱]；[實圖中的本鏡主體、物件與可見背景短句]。
[全部場景圖逐張一行：Image N、名稱／CLP id／視角，以及本鏡必要 CLP 特徵短句]。
[全部人物圖逐張一行：Image N、名稱／CLP id／視角，以及本鏡必要 CLP 特徵短句]。
[全部道具圖逐張一行：Image N、名稱／CLP id／視角，以及本鏡必要 CLP 特徵短句]。

二、本次分鏡設定

[依欄位選單取捨後，本鏡需送給引擎的設定；只寫採用內容，可合併為短段]。

三、參考圖使用規則

IMAGE 1 提供攝影機視角、攝影機取景範圍（VIEW）、攝影機方向、人物佔位與尺度，以及各元件的透視關係。
[實際場景圖引用] 提供場景設定，包含場景內的裝潢、家具、設備的造型、顏色與材質，以及前述各元素間的相對位置與空間定位；並提供場景的光影、色彩與氣氛。
[多張場景圖時填素材互補句；單張省略，具體歧義才補必要對應短句]。
[實際人物圖引用] 提供人物的外觀與服裝。
[實際道具圖引用] 提供配件的外觀與材質。

成果圖中，人物的表情、動作及其必要的道具互動狀態依第二段調整；其他可見元素均須依上述分工符合參考圖的內容，不得擅自新增、改變或刪除。
依 IMAGE 1 的鏡位與 VIEW 產生的透視、裁切及自然遮擋，不視為改變或刪除元素；場景本身的配置仍依 [實際場景圖引用] 的上述分工。

四、固定視覺風格

[本專案已核准美學與本鏡適用的表演、表面及明暗要求；保留人物／場景／道具參考的設計]。
[本鏡可見毛髮、服裝、場景及道具的材質紋理、反射與細節要求]。
[符合本鏡光線的補光、反射、陰影與立體層次；統一光源方向及色溫，色彩協調，重要表情與動作保持清楚]。

五、輸出

生成一張完整的 [核准比例] 彩色電影分鏡畫面，實際解析度依工具設定。
不呈現白模材質、Blender 介面、格線、座標軸、人物三視圖排版、道具展示背景、拼貼或說明文字。
```

### 工具綁定例

本例假設已選用 Nano Banana 2.1 與 2K：`image_selector` 使用 `preferred_tool="google_imagen"`、`model="gemini-nano-banana-2.1"`、`generation_mode="edit"`、`resolution="2K"`，`image_paths` 填有序素材清單；使用 Vertex JSON／global，比例依分鏡另填。模型與解析度是本例選擇，不是所有 W2I 的預設；實際綁定依 Director 第 2 節查所選工具。

以下僅說明 ESG 既有案例；人物、場景、道具與動作不套用其他課程或鏡頭。

## T2V

- 寫法：主體與環境 → 動作起點、過程、終點 → 相機運動 → 核准時長與攝影規格。
- 保持在該時長內可完成的一段動作，表演與秒數使用 Director 已確認的規劃；不添加首幀或參考素材條件。

### 填寫範本

```text
[主體、可見人數與環境]；[核准動作的起點、過程、終點與時間節點]。
[核准相機起訖、路徑與速度]。[核准時長與攝影規格]。
```

## I2V

- 以首幀承接外觀與起始構圖，Prompt 重點寫從該畫面開始的動作、時間節點與運鏡。
- 不限微動；大動作是否能完成依模型與實測。起始動作需與首幀相容，不重寫已由首幀確定的外觀，也不要求白模影片。
- 時長與攝影規格沿用核准規劃，首幀欄位依所選工具綁定。

### 填寫範本

```text
從 [首幀實際引用] 開始，承接其外觀與起始構圖；[與首幀相容的後續動作及核准時間節點]。
[核准運鏡、時長與攝影規格]。
```

## R2V

- 按共通引用規則分清角色／場景等參考用途，再寫動作起訖、時間節點、可見人數、運鏡與攝影規格；不要求白模或 W 類五段式。
- 構圖與拍攝方向依分鏡；首尾幀是可選時間條件，不是 R2V 的唯一意思。有使用時，動作及構圖須與對應時間點相容，依工具支援綁定。
- 普通參考圖提供身份／場景依據，不自行當成固定首幀；秒數沿用 Director 已確認的規劃。

### 填寫範本

```text
[實際參考素材的編號／名稱、用途及適用的 CLP 摘錄]。[有首尾幀時才填其對應時間條件]。
[可見人數、動作起訖與核准時間節點]。[核准構圖、運鏡、時長與攝影規格]。
```

## W2V

輸入白模預演影片與核准首幀；本節使用以下五段。首幀核准與白模需求依 Director 第 3.2 節；共通交接、工具能否承接及時長限制依第 3.1 節。

### 1. 素材職責宣告

- 列核准首幀與白模影片的實際名稱／用途：首幀承接外觀及起始構圖，白模影片提供運動與運鏡依據。
- 必要 CLP 只在所選工具支援且確有用途時附加；有附加時只在素材清單引用本次需要的特徵，不重貼 W2I 全文，也不另編或重複敘述首幀已確定的外觀。

### 2. 場景與起始構圖

- 明寫核准首幀與預演 t=0 的對應；背景隨預演鏡位變化，簡化白模不能替換首幀已確定的佈景外觀。
- 核對預演與首幀／場景佈局；真有結構衝突時回報修正素材／規劃，不要求模型同時遵從矛盾幾何。

### 3. 動作與表演

- 按 Director 的「表演來源」排列動作起點、節點與終點，承接首幀狀態；以白模影片引導人物運動及相機路徑。
- 白模影片是運動引導，不保證逐幀精確重現；指定表演與預演運動無法相容時回報調整，不默默捨棄其中一項。

### 4. 畫面構成

- 依分鏡交代各動作節點的景別、可見人數、前景與主體朝向；鏡外對話者保持為視線目標。
- 只有具體誤生風險才補短約束；人物出入畫面或構圖變化依規劃，不直接沿用 W2I 靜態畫面的限制。

### 5. 攝影與時間規格

- 寫入 Director 第 3.1 節對齊後的時長、動作節點時間，以及相機起訖與速度，不擅自發明秒數。
- 沿用已核准焦段、景深、光線方向、色調、比例；預演已固定的投影與運鏡不再附加矛盾的機位指令。效果仍須以生成結果檢視。
