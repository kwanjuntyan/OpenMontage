## 踩過的坑（核心結論）
- **rd_office 共用美術重繪**：參考全景可能把近景捲簾改成窗外景、把廣角簡模儀器換成參考造型；須逐鏡看圖列偏差，不能因指令有寫保留就判定幾何通過。工具回傳路徑的正則字面點只轉義一次，雙重轉義會解析失敗；修正解析即可，不需重生。
- **專案素材寫入**：projects 是指向 Dropbox 的 Junction；沙箱內可讀卻可能寫入 PermissionError，須針對使用者已指定的輸出與紀錄申請提升權限，無須重生圖片。
- **factory 側架與輸出**：v7 只改後牆，右牆重複箱列未更新，須看過肩底圖才能發現；v8 在3D內統一物料，只有標哥中景／側架過肩涵蓋改動。後牆物料轉側牆需朝室內旋轉−90°，避免背面朝鏡；Blender 5.2 逐件改hide_render會使all_objects即時迭代失效，先list快照再隱藏人物。存檔縮圖路徑曾警告，已另以重開模型與實際渲染確認成果可用。
- **factory 直管堆**：原腳本以 4／3／4／3 交錯排列且旋轉後按長寬高各自縮放，造成上層外擴及圓截面變形；改用真實圓管尺寸、5 至 1 根遞減與三角接觸高度，只作整捆剛體旋轉。正交檢視若完全順管軸看，會透孔見牆；保留中空構造，整捆小角度平行斜放讓管身可辨。
- **factory 管盤方向**：v5 把「一盤水管」做成正面朝鏡頭的直立螺旋，未符合使用者要的大捆平放；v6 改為軸線垂直、盤面水平的多圈厚管捆，以原機位確認姿態。
- **factory 堆放與變換**：不可用固定列距／整組外框落地替代逐件接觸；曲線實際管徑也可能不同於參數，應取求值後網格高度。旋轉後再非等比縮放會產生 Object TRS 無法保留的剪切，使採世界座標建點的曲線與附件分離；本次改成求值網格後將完整矩陣烘入頂點。接觸射線須排除待測物，從接觸點上方出發；由層板內往下射會誤把板厚當成懸空。
- **factory 塑膠箱**：細肋條配過強凹凸會像軟紙；角柱與橫框重疊共面會出現黑縫。保留硬直結構與粗框，減弱法線擾動並將相交構件接合成連續箱體；不能只靠歪斜既有整齊箱列製造雜物感。
- **Blender 5.2 天空節點／批次失敗判定**：本機 `ShaderNodeTexSky.sky_type` 使用 `MULTIPLE_SCATTERING`／`SINGLE_SCATTERING`，已不接受 `NISHITA`；先讀本機 RNA 枚舉。背景模式須帶 `--python-exit-code 1` 並檢查 `$LASTEXITCODE`，否則 Python 例外可能仍回傳程序成功，誤接著渲染舊 blend（2026-10-19 street 精修時確認）。
- **分鏡意圖與素材轉寫**：Scene Director 補充選填 `shot_intent` 的資訊／情緒目的寫法；Asset Director 補充圖片單一瞬間、影片首幀起始狀態與後續動作過程的區分，具體寫法仍依模態配方（2026-10-19）。
- **分鏡規劃資訊**：`kj-cinematic/scene-director.md` 補回動態鏡頭的動作起點、主要節點與終點及必要構圖／運鏡變化；標題或疊圖的內容與位置記於 `overlay_notes`，不混入實景描述（2026-10-19）。
- **Blender 場景與白模**：原檔多為 Workbench，切 Cycles 才顯示材質；本機 RTX 3050 Laptop GPU 搭配 Blender 5.2.2 LTS 時，Cycles GPU 須指定 `CUDA`（`OPTIX` 會因 `optix.ptx.copysign.f32` 編譯失敗報錯）；開啟子集合人物（如 `12 v008...`）須同時確認母集合 `07 People` 未設 `hide_render`；若 `LayerCollection` 設為 `exclude=True` 或 `hide_viewport=True`，Blender 不會計算其子物件的 `matrix_world`（回傳單位矩陣 `Identity(4)`），解開父子關係或讀世界座標前務必先將該 `LayerCollection` 取消隱藏並呼叫 `view_layer.update()`。全景檢查需暫時解除 timeline camera marker 綁定。 僅呼叫 image.pack() 不會保留零使用者的參考圖，須設定 use_fake_user=True 後儲存，並重新開檔確認仍有 packed_file。多影格關鍵影格綁定不同姿勢時，須先 `scene.frame_set(f)` 再設定物件姿態與 `keyframe_insert`，否則 `frame_set` 會先依既有 F-Curve 插值覆寫剛擺好的姿態；局部旋轉若物件帶 `rz=180°` 會翻轉局部 X 軸，後仰／轉頭一律以世界座標軸（`rotate_world_axis`）計算。修改道具／鋼架尺度須以模型公尺實測並重貼掛板、檢查前後排深度與覆蓋率。
- **W2I／R2I 生圖與構圖控制**：
  - W2I 唯一模板採「參考圖說明 → 生圖指引 → 單段畫面描述 → 輸出」，圖片固定按「場景 → blocks → 人物 → 道具」排序；以 blocks 為編輯底圖鎖定取景與佔位，場景圖僅供材質與光影，指定表演合併進畫面描述，不寫與 blocks 矛盾的指令。
  - **視角劫持（View Hijacking）**：特寫／過肩鏡只傳與本鏡朝向一致的場景參考圖，勿傳反向全局圖以免整間店旋轉 90 度。
  - **空椅入座（Occupy vs Spawn）**：I2I／W2I 置入人物寫「直接坐入既有木椅（入座佔用，不額外加椅）」，避免寫「保留所有桌椅」導致雙胞椅。
  - **驗收紀律**：AI 生成圖常有頭部放大、頭頂留白減少或局部配件增減，須逐張看圖驗收，不能僅因文字規則齊全或檔案存在就判定通過。
- **Schema 與 Manifest 規範**：`scene_plan` 與 `asset_manifest` 的項目皆為 `additionalProperties: false`；CLP 標註放 `required_assets[].clp_id` 與 `character_actions[].character_id`，manifest 記於 `generation_summary` 開頭（`clp: ... | ...`）。選填 `lens_mm` 若枚舉無實值則省略並記於描述。未知模型／費用省略不填 0。
- **Google／MiniMax API 細節**：
  - Nano Banana Pro／2.1 不支援 `negative_prompt`（改寫 `Avoid: ...`）；2K 回應含 `thought=true` 的 1376×768 草圖，adapter 已自動略過並取正式圖；費用保持 `unquoted`。
  - Omni 1.1 遇 HTTP 400 時須看回應本文區分參數錯誤與 `prohibited_content`（知名人物過濾，動畫圖亦可能觸發）。
  - MiniMax `emotion` 僅接受 9 種列舉值（無 `Neutral`），`<#0.4#>` 停頓原樣傳送；`output_format="hex"` 為傳輸編碼，WAV／MP3 設於 `audio_setting.format`。
- **Windows 與合成環境**：
  - PowerShell 勿用 `python -c` 塞複雜引號，改寫入 `.tmp/*.py` 並先設 `$env:PYTHONPATH=(pwd).Path; $env:PYTHONIOENCODING="utf-8"`。獨立腳本讀 `.env` 需先 `load_dotenv()`。
  - Windows 登錄檔易將 `.js` 誤設為 `text/plain` 致 Backlot 黑畫面，已在 `backlot/server.py` 強制設定 MIME。
  - FFmpeg 單圖 Ken Burns 禁止在 `zoompan` 前加 `-loop 1`，須先升 4K（3840×2160）超採樣再縮回 1080p/30fps 消除抖動。
  - **HyperFrames 渲染與素材裁切**：`projects/` 位於 Dropbox 同步區時，`npx hyperframes render --output` 直接指向 Dropbox 路徑易因同步鎖定暫存目錄觸發 `EBUSY` rename 失敗，應先輸出至 `.tmp/<shot_id>.mp4` 再複製回 `assets/videos/`；HTML 圖卡引用 `clp/` 三視圖（人物／道具 turnaround sheet）時，須先裁切或以 CSS `object-fit`/`object-position` 鎖定正面單一視圖，勿整張縮小塞入圖框；每支圖卡結尾禁止淡出至黑畫面以維持剪輯連貫。
